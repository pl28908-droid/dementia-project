The approach

Support built around the individual.

The prototype focuses on recording activity interactions, understanding session-level patterns, and making stored personal notes easier to revisit.

01 / ENGAGE

Interactive activities

Short memory, sequence-recall and attention activities with adjustable difficulty and measurable session metrics.

02 / UNDERSTAND

Behavioral insights

A Scikit-learn pipeline demonstrates how structured session metrics can be analyzed and categorized for a prototype workflow.

03 / RECALL

Personal memory notes

Caregiver- or family-entered notes can be stored and retrieved through a simple API, with future scope for semantic retrieval.

Technology

Built with a practical ML-first stack.

Modular Python code separates data generation, model training, inference, database access and API routes.
