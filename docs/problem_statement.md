# Problem statement

People supporting older family members may need simple ways to engage in structured cognitive activities and keep personally meaningful notes accessible. SMARAN explores a software prototype that combines interactive activity sessions, session-level behavioral metrics, adaptive activity suggestions, and family/caregiver-entered memory notes.

## Goals
1. Provide a small set of repeatable cognitive-style activities.
2. Capture transparent session metrics such as accuracy, time, mistakes and score.
3. Demonstrate an ML workflow on synthetic session data.
4. Expose functionality through documented APIs.
5. Store user-provided memory notes with basic metadata.

## Non-goals
- Diagnosing dementia or any medical condition.
- Replacing clinicians, caregivers, or professional assessment.
- Making claims about cognitive decline from a single score.
- Treating synthetic training data as clinical evidence.
